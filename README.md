# Équipes express

Petite appli web pour former des équipes rapidement.

- **Avec des noms** : saisie des prénoms, nombre d'équipes (2 à 8), tirage au sort équilibré.
- **Avec les doigts** : chacun pose un doigt sur l'écran, plusieurs tours possibles si l'écran ne détecte pas assez de doigts (5 sur iPhone, souvent 10 sur Android).

Un seul fichier `index.html`, sans dépendance à installer.
